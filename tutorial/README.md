# Galactic Gradebook — Tutorial

Build the app yourself, chapter by chapter.

| Language | |
| --- | --- |
| 🇬🇧 **English** | [`en/README.md`](en/README.md) |
| 🇩🇪 **Deutsch** | [`de/README.md`](de/README.md) |

Both versions cover the same 17 topic pages and the same exercises. Pick one and stay with it —
they build on each other.

Those pages are cut by **topic**. Next to them there is a second track that builds the same
project **step by step** in 21 chapters — hardcoded data first, a login button that only navigates,
a single academy — see [`de/build/`](de/build/README.md). It exists **in German only for now**;
the English translation is still to come.

## What's next to them

| Folder | |
| --- | --- |
| [`de/build/`](de/build/README.md) | the step-by-step build track, 21 chapters (German only for now) |
| [`de/konzepte/`](de/konzepte/) | the topic pages the chapters link to (German; the English ones still sit in [`en/`](en/)) |
| [`playground/`](playground/) | runnable exercises for the language chapters (01–03) |
| [`vorlagen/`](vorlagen/) | DevContainer and Vite templates to copy into **your** project |

The exercises and templates are shared: code and configuration are the same in every language,
only the explanations differ. The build track is the one exception — it is not shared yet.
